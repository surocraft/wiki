# 🌍 PROPOJENÍ ÚČTŮ

Jedna z oblíbených funkcí SuroCraftu mezi hráčemi je propojení Java a Bedrock účtů.  
Díky tomu můžeš hrát na jednom účtu z různých zařízení.

- Máš sdílený progress mezi platformami,
- samozřejmě i inventář, polohu, rezidence, pozemek, a další,
- VIP si platíš jen jedno,
- a v neposlední řadě sloučený playtime.

Propojení účtů by ti mělo vzít maximálně 5 minut. Je to easy!

::: danger Bedrock účet ztratí postup!
Java účet má prioritu a progress z bedrock účtu bude přepsán.  
Ulož si věci z bedrock účtu do bedny.
:::

Protože java účet má prioritu, je potřeba **začít s krokem 1 na Javě:**

1. Použij **`/linkaccount <Bedrock nickname>`** (__NA JAVĚ__, [bedrock nejde]) 
2. Zapsat si kódík z příkazu (`XXXX`)
3. Použij **`/linkaccount <Java nickname> XXXX`**
4. **Propojeno!** (Bedrock účet se odpojí a může se znova připojit už jako napárovaný)

Kdybys chtěl účty odpojit, stačí použít **`/unlinkaccount`**.
