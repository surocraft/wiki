# 💻 JAK SE PŘIPOJIT

SuroCraft podporuje jak Minecraft Java Edition, tak i Bedrock Edition.  
Níže najdeš více informací.

:::tabs
== JAVA EDITION
> `mc.surocraft.eu`

**Verze:** `1.9` a vyšší  
**Warez:** povolen
== BEDROCK EDITION
> `mc.surocraft.eu`  
> `19132`

**Verze:** `1.21.70` a vyšší
:::

Pro přístup na server nemusíš žádat o whitelist.  
Dodržuj [pravidla serveru](../pravidla).

::: tip DISCORD
Nezapomeň se připojit na náš [Discord server](https://dsc.gg/surocraft).  
Najdeš tam hodně informací a hlavně budeš s ostatními v kontaktu i mimo hru.
:::
